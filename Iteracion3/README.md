# Autos Colombia - Iteración 3

Aplicación web desarrollada en Python, Flask y SQLite para la administración de un parqueadero.

En esta tercera iteración se incorporó la gestión de pagos de mensualidades, permitiendo registrar pagos anticipados, generar recibos en PDF y consultar el historial de pagos de los vehículos.

Se conservan las funciones de las iteraciones anteriores: registro de vehículos, entradas y salidas, administración de usuarios, celdas y auditoría.
